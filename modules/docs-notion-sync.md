# 모듈: Notion 및 협업 문서 안전 동기화 규칙

- 적용: Notion MCP 또는 협업 위키(Jira, Confluence 등) 문서를 AI가 조회·작성·갱신하는 경우
- 상위 지침: [`../AGENTS.md`](../AGENTS.md)

## 1. 핵심 원칙 (쓰기 전·후 검증 루프)

AI가 외부 협업 문서를 수정할 때는 **명시적 사용자 요청이 있을 때만** 쓰기 도구를 호출하며, 다음 4단계 검증 루프를 따른다.

```text
1. 선조회 (Fetch) ──> 대상 페이지/DB 스키마, 기존 본문·이력, 중복 여부 확인
2. 통합·최소 수정  ──> 새 페이지 남발 금지(기존 페이지 갱신 우선), 필요한 영역만 수정
3. 재조회 (Verify) ──> 쓰기 성공 응답만으로 완료 처리하지 않고 재조회해 실제 반영 확인
4. 이력 갱신       ──> 수정 일시, 수정 주체, 실제 수행한 검증 근거 기록
```

### 재조회 시 필수 확인 항목
- 요청한 내용이 정확한 위치에 반영됐는가
- 기존 본문이나 이전 수정 이력이 의도치 않게 삭제·덮어쓰기 되지 않았는가
- 동일한 내용의 중복 문서가 생성되지 않았는가
- 확인되지 않은 추측을 `확정` 또는 `완료`로 표기하지 않았는가

---

## 2. 연결 불가·권한 미확인 시 Fallback

Notion MCP 연결이 끊겨 있거나 사용자의 수정 요청 권한이 확인되지 않았다면 작업을 중단하지 않는다.

- 확인하지 못한 외부 문서 내용을 추측으로 단정하지 않는다.
- 실제 쓰기 호출 대신 사용자가 검토 후 바로 붙여 넣을 수 있는 **등록용 초안(Draft)**을 출력한다.
- 연결이 복구되면 기존 페이지 위치와 중복 여부를 먼저 재조회한 뒤 반영한다.

## 3. 수정 이력 표준 (4열 표)

여러 주체(사용자, Claude, Codex, Gemini 등)가 같은 문서를 편집할 때 변경 출처와 검증 수준을 분리한다.

| 일자 | 변경 내용 | 수정 주체 | 검증 상태·근거 |
|---|---|---|---|
| YYYY-MM-DD | 변경한 핵심 내용 | Claude | 정적 소스 확인 — 관련 파일 경로 및 범위 |
| YYYY-MM-DD | 테스트 결과 반영 | Gemini | 브라우저 검증 — 로컬 환경 시나리오 N건 |
| YYYY-MM-DD | 최종 범위 승인 | 사용자 | 담당자 협의 결과 확인 |

- **수정 주체 원칙**: 실제로 해당 변경에 참여한 주체만 기록한다. 다른 주체의 검토를 임의로 공동 표기하지 않는다.
- **검증 상태 표현**: AI가 작성했다는 이유만으로 `완료`·`확정`으로 쓰지 않고 `문서 원문 확인`, `정적 소스 확인`, `실행 검증`, `브라우저 검증`, `사용자 확인`, `추가 확인 필요`, `미검증` 중 사실에 맞는 상태를 사용한다.
- **기존 표 호환 및 보존**: 기존 문서가 `일자 | 변경 내용 | 비고` 3열 표를 쓰면 구조를 강제로 깨지 않고 `비고`에 `수정 주체 / 검증 근거`를 병기한다. 기존 이력 행은 덮어쓰지 않고 새 행을 추가한다.
- **충돌 처리**: AI 간 분석 결론이 다르면 최신 작성자 기준으로 덮어쓰지 않고, 원문·소스·실행 결과를 다시 대조해 근거가 확인된 쪽으로 정정 이력을 남긴다. 과거 이력의 작성자가 기록되어 있지 않으면 추측하지 않고 `확인 불가`로 둔다.

## 4. 표준 작업 기록 양식 (템플릿)

```markdown
### 작업명
- 대상 범위: (시스템/메뉴/URL/PC·모바일)
- 작업 유형: 소스 분석 / 진단 / 개선안 검토 / 개발 / QA / 재검증
- 문제 및 근거: (현재 구현, 적용 기준, 확인/제외 범위)
- 관련 파일: (호출 확인 파일 vs 실제 수정 파일)
- 처리 내용: (적용 변경, 미적용 대안과 이유)
- 검증 결과: (실제 수행 항목 vs 미수행 항목과 이유)
- 상태: 분석 중 / 개발 완료 / 재검증 필요 / 차단 / 보류 / 완료
```

## 5. 협업 문서 기록 금지 정보

외부·공유 문서에는 다음 정보를 절대 기록하지 않는다.

- 개인정보, 실제 사용자 계정 비밀번호, 인증키, 세션 토큰
- 운영 DB 접속 정보 및 실제 운영 데이터
- 불필요하게 긴 에러 스택트레이스나 전체 소스 코드 복사본
- 외부 공개 시 보안 위험이 되는 내부 서버·인프라 설정
