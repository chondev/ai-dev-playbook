# 모듈: 다중 AI 에이전트 역할 분리 및 협업 인계

- 적용: 복수의 AI 도구(예: 구현 / 검증 / 독립 QA)를 병행해 작업을 분할·교차 검증하는 프로젝트
- 상위 지침: [`../AGENTS.md`](../AGENTS.md)
- 협업 문서(Notion 등) 상세 편집 규칙: [`docs-notion-sync.md`](docs-notion-sync.md)

## 1. 역할 분리 모델 (권장)

```text
[사용자 (범위·커밋·배포 최종 결정)]
  ├─ [구현 담당 에이전트] ──> 소스 조사·최소 수정·자체 테스트·구현 보고
  ├─ [검증 담당 에이전트] ──> (읽기 전용) 진입 경로·diff·테스트 근거 교차 검증
  └─ [독립 QA 에이전트]  ──> (읽기 전용) 회귀 위험·누락·미검증 항목 재검토
```

- **구현 담당**: 대상 매핑, 관련 소스 조사, 최소 수정, 수정 직후 자체 테스트, 작업별 구현 보고를 맡는다.
- **검증 담당 (읽기 전용)**: 범위, 진입 경로, `diff`, 검증 근거, 커밋 후보 완결성을 검토한다. 별도 지시 없이 소스 파일을 직접 수정하지 않는다.
- **독립 QA (읽기 전용)**: 구현 결과와 검증 결과를 교차 검토해 회귀 위험, 누락, 미검증 사유를 정리한다.

## 2. 파일 충돌 방지 및 인계 원칙

- 동일 파일을 여러 에이전트가 동시에 수정해 충돌이 나지 않도록 작업 전 파일 소유권을 명시하고 격리한다.
- 공통 자원(Layout, 공통 CSS/JS, 공통 include)은 영향 범위 매핑과 사용자 승인 후 **단일 주체만 수정**하고, 검증·QA 에이전트가 순차 검토한다.
- 작업 인계 시에는 `작업 ID`, `대상 URL/화면`, `기준 커밋/리비전`, `실제 수정 파일`, `수행한 테스트와 미수행 사유`를 명확히 남긴다.
