# 정적 문법 회귀 점검 도구

마크업(안내 `<span>`, `aria-*` 속성 등)이나 스크립트를 수정한 뒤, 커밋 전에 구문 깨짐을 빠르게 잡기 위한 정적 점검 도구입니다.

| 스크립트 | 검사 대상 | 실행 예시 |
|---|---|---|
| [`jsp_tag_attr_check.py`](jsp_tag_attr_check.py) | JSTL/커스텀 태그 속성(`<c:set value="...">` 등) 내부에 같은 따옴표가 중첩되어 Jasper 컴파일 오류가 나는 패턴 검출 | `python tools/jsp_tag_attr_check.py <대상_WEB-INF_경로>` → `hits 0` 확인 |

검사 전에 대상 디렉터리에 변경한 `.jsp`, `.jspf` 또는 `.tag` 파일이 있는지 확인합니다. 검사 대상이 비어 있어도 도구는 `hits 0`을 출력합니다. 결함을 발견한 경우에도 정상 종료할 수 있으므로 결과를 기록할 때는 대상 파일과 출력된 `hits` 값을 함께 확인합니다.

서버에서 JSP가 컴파일되는지, 입력 오류 시 안내와 초점 이동이 동작하는지는 실제 화면에서 별도로 확인합니다.
